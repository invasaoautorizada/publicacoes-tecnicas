# Linux na Prática — Primeiros Passos no Terminal

**E-book gratuito | Caderno de iniciação ao Linux**

Este material apresenta os primeiros passos para aprender
a utilizar o terminal Linux, com explicações didáticas,
comandos essenciais e exercícios práticos.

## O que você vai aprender

- Conhecer o terminal Linux
- Identificar usuário e diretório atual
- Navegar pelo sistema de arquivos
- Criar, copiar, renomear e remover arquivos
- Consultar arquivos e utilizar comandos de ajuda
- Compreender noções iniciais de permissões
- Realizar uma missão prática
